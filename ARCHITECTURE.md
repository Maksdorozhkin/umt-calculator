


**Ключи localStorage:**
| Ключ | Описание |
|---|---|
| `umt_products_cache` | Справочник продукции (массив) |
| `umt_machine_product_cache` | Привязка продукт→машина (`{ "1": {...} }`) |
| `umt_downtime_cache` | Логи простоев по машинам (`{ "1": [...] }`) |
| `umt_offline_queue` | Очередь отложенных POST/DELETE запросов |
