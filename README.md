# UMT формовка

Калькулятор ЮМТ - формовка

### 🖥️ 7 машин  
для контроля выпускаемой продукциии, показывает сколько сделаешь за смену и сколько до конца смены, также есть лог простоев (в дальнейшем реализую эти дурацкие чек листы)

### 📊 Отчет по простоям

Нажмите на заголовок «⏱ Лог простоев» на панели машины — откроется отчет с таблицей всех простоев:

| Время | Причина | Длительность | Примечание |
|-------|---------|-------------|------------|
| 14:30 | Ролик (7 мин) | 7 мин | Запасной ролик |

**Причины:**
- **Ролик (7 мин)** — замена ролика (7 мин)
- **Ролик (15 мин)** — замена ролика (15 мин)
- **Произвольный** — ручной ввод длительности и причины

### 🧮 Калькулятор ленты

Сделан на основе формулы из excel, считает также, при желании могу сделать точнее (с ПЭТ еще эксперементирую) 

| Вводишь | Получаешь |
|---------|-----------|
| Вес изделия + отходность + кол-во изделий | Сколько ленты нужно |
| Вес изделия + отходность + кг ленты | Сколько изделий выйдет |
| Толщину намотки + ширину рулона | Вес рулона в кг |

**Чекбоксы:**
- **ПЭТ** — переключает тип ленты (по умолчанию ПП)
- **ПП Железная шпуля (16 см)** — для ПП с маленькой шпулей

### 🌙 Смена определяется сама

Сделал так потому что на смену вовремя не приходит (предлогаю всем писать коментарий передача смены)

- **Дневная:** 8:00–19:50 → светлая тема
- **Ночная:** 20:00–7:50 → тёмная тема

Глаза скажут спасибо.

### 📐 Калькулятор изделий

Считает количество изделий ±5% от заказа.
