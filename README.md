# UMT формовка

Калькулятор для цеха — считай выпуск, ленту и простои, не ломая голову.

---

## Что умеет

### 🖥️ 7 машин — 7 калькуляторов

Выбираешь машину, вводишь параметры продукции, и всё считает само:

- **Наименование** — можно выбрать из сохранённого справочника (автодополнение)
- **Кавитации** — сколько полостей в форме
- **Такты в минуту** — как быстро работает машина
- **Штук в коробке** / **Коробок на паллете** — для красивого вывода результата

### 📦 Выпуск за смену

Смена = 710 минут (11ч 50м). Результат показывается в понятном формате:

- `2п. 4кор.` — набралось паллеты и ещё коробки
- `14кор.` — паллет нет, но коробки есть
- `38шт.` — даже коробка не набралась

Обновляется автоматически, как только поменяешь кавитации, такты или упаковку.

### ⏱️ Простой — фиксируем и считаем

Если машина встала — добавляй простой:

- Замена ролика (7 мин)
- Замена ролика (15 мин)
- Свой простой (вводишь минуты сам)

Записи можно удалять кнопкой ✕. Всё автоматически вычитается из доступного времени.

### ⚡ Производительность в час

Сколько машина выдаст за час — видно наглядно. Формат тот же: паллеты, коробки, штуки. Если данные не заполнены — покажет `--`.

### 🧮 Калькулятор ленты

Три режима, переключаются сами:

| Вводишь | Получаешь |
|---------|-----------|
| Вес изделия + отходность + кол-во изделий | Сколько ленты нужно |
| Вес изделия + отходность + кг ленты | Сколько изделий выйдет |
| Толщину намотки + ширину рулона | Вес рулона в кг |

**Чекбоксы:**
- **ПЭТ** — переключает тип ленты (по умолчанию ПП)
- **ПП Железная шпуля (16 см)** — для ПП с маленькой шпулей

### 🌙 Смена определяется сама

- **Дневная:** 8:00–19:50 → светлая тема
- **Ночная:** 20:00–7:50 → тёмная тема

Глаза скажут спасибо.

### 📐 Калькулятор изделий

Считает количество изделий ±5% от заказа. Просто, быстро, без лишних кликов.

### 📖 Страница «О приложении»

Справка внутри приложения — открывается по ссылке внизу главной страницы. Всегда актуальная, потому что берёт данные прямо из этого README.

## Как пользоваться

1. Выбери машину сверху
2. Введи данные о продукции (или выбери из списка)
3. Нажми **«Сохранить»** — попадёт в общий справочник
4. Нажми **«Посчитать»** — увидишь выпуск до конца смены
5. Данные продукта работают на всех машинах

### Фиксируем простои

1. Выбери тип простоя (или введи свои минуты)
2. Добавь примечание (необязательно)
3. Нажми **«Добавить простой»**
4. Удалить — кнопка ✕
