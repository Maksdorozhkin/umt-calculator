# UMT формовка

### 🖥️ 7 машин  
Для контроля выпускаемой продукциии, показывает сколько сделаешь за смену и сколько до конца смены (удобно для закрытия смены)

### 🎯 Прогноз «до конца смены»

Сколько паллет, коробок и штук станок ещё успеет до конца смены:

- **Остаток времени** — до конца смены (с учётом смещения −10 мин).
- **Активный простой** — если прямо сейчас идёт простой (например, замена ролика), из остатка вычитается только его «хвост» — сколько минут осталось до конца простоя.
- **Завершённые простои** — не вычитаются: своё время они уже «отобрали».
- **Будущие простои** — не учитываются (их ещё нет).
- **Расчёт** — сначала штуки: `(время × такты/мин × кавитации)`, затем целочисленно: паллеты → коробки → штуки (без дробных ошибок).

### 📊 Отчет по простоям
Нажми на «Лог простоев» на панели машины — откроется отчет со всеми простоями за смену которые были отмечены.

**📋 Копировать лог:**
Нажми «📋 Копировать» рядом с заголовком лога — скопирует отформатированный отчёт по простоям в буфер обмена. Удобно для отправки в чат.

Каждая запись показывает:
- **Время** — когда произошла поломка
- **Причина** — что сломалось
- **Длительность** — сколько минут простаивала машина
- **Примечание** — дополнительные детали (например, «Замена ролика»)

**Причины:**
- **Ролик (7 мин)** — замена ролика (7 мин)
- **Ролик (15 мин)** — замена ролика (15 мин)
- **Произвольный** — ручной ввод длительности и причины

### 🧮 Калькулятор ленты

Сделан на основе формулы из excel, считает также, при желании могу сделать точнее (с ПЭТ еще экспериментирую)

**Что умеет:**
- 📦 **Изделия → лента** — вводишь вес изделия + отходность + кол-во изделий → получаешь сколько ленты нужно
- 🔄 **Лента → изделия** — вводишь вес изделия + отходность + кг ленты → получаешь сколько изделий выйдет
- ⚖️ **Вес рулона** — вводишь толщину намотки + ширину рулона → получаешь вес рулона в кг

**Чекбоксы:**
- **ПЭТ** — переключает тип ленты (по умолчанию ПП)
- **ПП Железная шпуля (16 см)** — для ПП с маленькой шпулей

### 🌙 Смена определяется сама
- **Дневная:** 8:00–19:50 → светлая тема
- **Ночная:** 20:00–7:50 → тёмная тема

### 📐 Калькулятор изделий
Считает количество изделий ±5% от заказа.
**Режимы работы:**
- **Только «Весь заказ»** — вводишь заказ, поле «осталось» не трогаешь → расчёт идёт от всей суммы заказа (10 000 → осталось +5% = 10 500, −5% = 9 500)
- **Отрицательное число** — вводишь `-1000` как в ERP → значит осталось доделать 1000 штук, расчёт идёт от этого остатка
- **Положительное число** — заказ выполнен, вводишь сколько сделано сверх → расчёт показывает сколько ещё нужно для +5%

Если заполнены поля «Штук в коробке» и «Коробок на паллете» — дополнительно показывает разбивку по паллетам и коробкам.

### 📱 Pull-to-Refresh — обновление свайпом вниз
На главной странице вместо кнопки обновления — жест pull-to-refresh.
**Как работает:**
- Потяни экран вниз от верха страницы → появится полоса обновления со спиннером

### 📱 PWA — установка на телефон и работа без интернета

Приложение можно установить на Android / iOS как полноценное приложение — без браузера, без адресной строки, с иконкой на рабочем столе.

**Как установить:**
- **Android (Chrome):** открыть `umt.mdorozhkinvlog.ru` → меню браузера (⋮) → «Установить приложение» / «Добавить на главный экран»
- **iOS (Safari):** открыть `umt.mdorozhkinvlog.ru` → кнопка «Поделиться» (⬆) → «На экран „Домой“»

**Что умеет в офлайн-режиме:**
- 🧮 **Расчёт выпуска** — калькулятор работает полностью без сервера. Формула `количество = время × такты × кавитации` выполняется в браузере, учитывает оставшееся время смены и «хвост» активного простоя (данные — из локального кэша)
- 📥 **Справочник продукции** — загружается из localStorage мгновенно, даже при полном отсутствии сети. При появлении интернета обновляется с сервера в фоне
- 🏭 **Привязка продукта к машине** — кэшируется в localStorage (`umt_machine_product_cache`). При офлайн-запуске форма заполняется из локального кэша
- 📋 **Логи простоев** — добавление/удаление записей работает офлайн через localStorage. Записи помечаются временным ID и синхронизируются с сервером при появлении связи
- 🗑️ **Удаление продуктов** — работает офлайн: продукт удаляется из локального кэша, удаление синхронизируется с сервером позже
- 💾 **Сохранение продуктов** — при недоступности сервера данные сохраняются в localStorage с уведомлением «сохранён офлайн»
- 📤 **Очередь записей** — все создать/удалить запросы автоматически ставятся в очередь и отправляются при восстановлении связи
- ⏱️ **Автосинхронизация** — при появлении сети очередь отправляется мгновенно, плюс проверяется каждые 30 секунд. После синхронизации все кэши перезагружаются с сервера
- 🔋 **Полный офлайн** — интерфейс не ломается: уведомления типа «info» показывают, что операция выполнена локально

### ⚖️ Баланс смены

Компактный блок внизу панели каждой машины — помогает мастеру сразу увидеть расхождение между фактом и планом.

- **✅ Факт выпуска** — два поля ввода: паллеты и коробки (например `3 п. 12 кор.`). Сохраняется и восстанавливается при перезагрузке.
- **⏱ Прошло времени** — автоматически от начала смены (08:00 или 20:00).
- **📊 Должно быть** — `(прошло_времени − записанные_простои) × такты/мин × кавитации`, отображается в паллетах и коробках.
- **🔍 Разница** — `факт − расчёт` в паллетах и коробках (округление до целой коробки вниз). Показывает отставание или опережение.
- **⚠️ ≈ Неучтённый простой** — разница пересчитана в минуты: `(разница) / (такты × кавитации)`. Появляется, когда факт меньше расчёта.
- **Прогресс-бар** — визуальный процент выполнения (`факт / должно_быть`).

| 🟢 Зелёный | ✔ Данные сходятся |
| 🔴 Красный | ⚠ Забыл указать простой |
| 🟡 Жёлтый | Опережаем |
