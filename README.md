# UMT формовка

## Функционал

### 1. Калькуляторы для 7 машин
- Ввод данных о продукции:
  - Наименование продукции (с автодополнением из общего справочника)
  - Количество кавитаций
  - Количество тактов в минуту
  - Штук в коробке
  - Коробок на паллете

### 2. Лог будущих простоев
Для каждой машины можно фиксировать:
- Замена ролика (7 минут)
- Замена ролика (15 минут)
- Произвольный простой (указывается время в минутах)
- Удаление записей о простоях (кнопка ✕)

### 3. Индикатор производительности в час
Для каждой машины отображается ожидаемый выпуск продукции в час:
- Расчёт: `кавитации × такты/мин × 60 = шт/час`
- Формат вывода:
  - `2п. 4кор.` - если набирается ≥1 паллета в час
  - `14кор.` - если паллет нет, но коробка набирается
  - `38шт.` - если и коробка не набирается
  - `--` - если данные не заполнены
- Автообновление при выборе продукта, сохранении и смене простоя
- Отображается в строке с "Доступным временем" и "Общим простоем"

### 4. Калькулятор ленты
Отдельный модуль для расчета ленты, изделий и веса рулона (три режима):

**Прямой расчёт (изделия → лента):**
- Средний вес изделия
- Отходность в процентах
- Требуемое количество изделий
- Результат: необходимое количество ленты, с запасом +10%, отход/дроблёнка

**Обратный расчёт (лента → изделия):**
- Средний вес изделия
- Отходность в процентах
- Доступно ленты (кг)
- Результат: сколько можно произвести изделий, отход/дроблёнка

**Расчёт веса рулона (по толщине намотки):**
- Чекбокс «ПЭТ» — переключатель типа ленты (по умолчанию **ПП**)
- Толщина намотки (см) — измеряется линейкой от края втулки до внешнего края рулона
- Ширина рулона (см)
- Результат: вес рулона в кг
- Формулы:
  - **ПП** (заводская, из Excel): `((t × 2 + 18)² − 324) × w / 1413`, диаметр шпули = 18 см
  - **ПЭТ** (теоретическая, заводского нет): `π × ((t + 8)² − 8²) × w × 0,00138`, диаметр шпули = 16 см
  - `t` — толщина намотки (см), `w` — ширина рулона (см)
- Этот режим работает без ввода среднего веса, отходности и количества изделий

Калькулятор определяет режим автоматически:
- Заполнено «изделия» → считает ленту
- Заполнено «лента» → считает изделия
- Заполнены только радиус и ширина → считает вес рулона

### 5. Определение смены
- Дневная смена: 8:00 - 19:50
- Ночная смена: 20:00 - 7:50
- Автоматическое переключение темы (светлая/темная) в зависимости от смены

### 6. Калькулятор изделий
Отдельный модуль расчета изделий 
- Калькулятор считает количество +- 5% от заказа

### 7. Страница "О приложении"
Встроенная страница справки с актуальным описанием функционала:
- Доступна по ссылке «📖 О приложении» внизу главной страницы
- Открывается на отдельной странице `/about` (адаптировано под мобильные)
- Контент подтягивается из `README.md` автоматически — при обновлении README страница справки обновляется сама
- Стилизована под текущую тему приложения (светлая/темная)

### Работа с машинами
1. Выберите машину во вкладках сверху
2. Заполните данные о продукции (или выберите из списка)
3. Нажмите "Сохранить" - данные сохранятся в общий справочник
4. Нажмите "Посчитать" для расчета выпуска до конца смены
5. Данные продукта будут доступны для всех машин

### Расчёт производительности
Индикатор обновляется автоматически при загрузке данных продукта. Для пересчёта измените кавитации, такты/мин, штуки в коробке или коробки на паллете.

### Фиксация простоев
1. Выберите тип простоя
2. При произвольном простое укажите время в минутах
3. Добавьте примечание (необязательно)
4. Нажмите "Добавить простой"
5. Для удаления записи нажмите кнопку ✕ рядом с записью

### Расчет ленты
1. Перейдите во вкладку "Калькулятор ленты"
2. Выберите **один** из трёх режимов:

   **Режим 1: Прямой расчёт (изделия → лента)**
   - Средний вес изделия (в граммах)
   - Отходность (в процентах)
   - Требуемое количество изделий
   → Результат: нужное количество ленты, запас +10%, отход/дроблёнка

   **Режим 2: Обратный расчёт (лента → изделия)**
   - Средний вес изделия (в граммах)
   - Отходность (в процентах)
   - Доступно ленты (кг)
   → Результат: возможное количество изделий, отход/дроблёнка

   **Режим 3: Расчёт веса рулона**
   - ☑ ПЭТ — отметьте, если используется лента ПЭТ (по умолчанию ПП)
   - Толщина намотки (см) — линейкой от края втулки до края рулона
   - Ширина рулона (см)
   → Результат: вес рулона в кг
   *(Не требует ввода веса изделия, отходности и количества)*

   **Типы ленты и параметры шпули:**

   | Тип | Диаметр шпули | Формула | Когда ставить ☑ ПЭТ |
   |-----|---------------|---------|----------------------|
   | **ПП** | 18 см | Заводская Excel: `((t×2+18)²−324) × w / 1413` | Чекбокс **не** отмечен (по умолчанию) |
   | **ПЭТ** | 16 см | Теоретическая: `π × ((t+8)²−64) × w × 0,00138` | Чекбокс отмечен |

3. Нажмите "Рассчитать"
